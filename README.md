# CCNA Capstone – Global Logistics Network

## Overview
This project simulates a multi-branch enterprise network using Cisco Packet Tracer and EIGRP routing.

## Technologies Used
- Cisco Packet Tracer
- EIGRP
- VLANs
- Trunking
- Network Security

## Features
- Multi-branch connectivity
- VLAN segmentation
- Dynamic routing using EIGRP
- Secure device configuration
- Network troubleshooting and verification
